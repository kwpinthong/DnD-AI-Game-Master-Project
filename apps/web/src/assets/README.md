# UI assets (apps/web/src/assets)

ที่เก็บไฟล์ภาพของหน้าเว็บเกม Isekai Chronicles ไฟล์ในโฟลเดอร์นี้ถูก import จากโค้ด แล้ว Vite จะใส่ hash ในชื่อไฟล์ตอน build (cache ได้นาน ไม่ต้องกลัวไฟล์เก่าค้าง)
ไฟล์ที่ต้องมีชื่อคงที่ (favicon, รูปแชร์ลิงก์) ให้วางใน `apps/web/public/` แทน ดู README ในโฟลเดอร์นั้น

## โฟลเดอร์

| โฟลเดอร์ | ใส่อะไร | รูปแบบ |
|---|---|---|
| `icons/` | ไอคอนในปุ่ม, badge, สถานะ (เปิดเผย / ลับ, HP, Stamina, อากาศ, ช่วงเวลา, กรรม, เดินทาง) | SVG เท่านั้น |
| `ornaments/` | ลายเส้นแฟนตาซี: เส้นคั่น, มุมกรอบ, ตราหัวหน้า (ตาม tone v2 ของ GEN-085) | SVG |
| `illustrations/` | ภาพประกอบใหญ่: หน้า empty state, หน้าจบเกม, ภาพสถานที่ / ภาพ NPC | WebP (ภาพวาด / ภาพถ่าย) หรือ SVG (ภาพลายเส้น) |
| `textures/` | พื้นผิวเบา ๆ ที่ปูซ้ำ (noise, กระดาษ, ดาว) | WebP หรือ SVG ที่ต่อขอบกันได้ (seamless) |
| `frames/` | กรอบและพื้นปุ่มที่วาดไว้: `frame-clock` (นาฬิกา HUD), `frame-panel` (แผงขวา), `btn-primary` (ปุ่มหลัก), `avatar-ring-{f,b,a,s,ss,player}` (กรอบรูปตามเกรด) ดูวิธีใช้ใน `frames/CREDITS.md` ไฟล์ชั่วคราว จะถูกแทนด้วยชื่อเดิม | WebP พื้นโปร่ง |
| `fonts/` | ใช้เฉพาะถ้า Q-190 เลือก self-host font | WOFF2 เท่านั้น |

ถ้าไม่แน่ใจว่าใส่ที่ไหน ให้ใส่ `illustrations/` แล้วบอก Claude

## รูปแบบไฟล์

### ไอคอน (`icons/`)
- SVG ขนาด viewBox `0 0 24 24` เส้นหนา 1.5–2 px ปลายเส้นมน ไม่มีพื้นหลัง
- ใช้ `currentColor` แทนสีจริงทุกจุด (`stroke="currentColor"` หรือ `fill="currentColor"`) เพื่อให้สีมาจาก token ของ theme (`--accent`, `--secret`, `--danger` ...) ห้ามใส่สี hex ในไฟล์
- ลบ `width` / `height` คงที่ออก เหลือแค่ `viewBox` ขนาดกำหนดด้วย CSS
- ลบ metadata ที่โปรแกรมวาดใส่มา (Figma / Illustrator) ไฟล์ละไม่เกิน 2 KB
- ไอคอนต้องมีคำกำกับเสมอในหน้าเว็บ (ข้อความข้าง ๆ หรือ `aria-label`) ห้ามสื่อความหมายด้วยไอคอนหรือสีอย่างเดียว เช่น badge ลับต้องมีคำว่า "ลับ"

### ลายเส้นแฟนตาซี (`ornaments/`)
- SVG ใช้ `currentColor` เหมือนไอคอน เพื่อเปลี่ยนสีตาม theme ได้
- เส้นบาง (1–1.5 px) ตามโทน "สะอาด + กลิ่นแฟนตาซีเล็กน้อย" ไม่หนาหรือรกจนแย่งตัวหนังสือ

### ภาพประกอบ (`illustrations/`)
- ภาพวาด / ภาพถ่าย: WebP คุณภาพ 75–85
  - ภาพกว้างเต็มหน้า: กว้าง 1600 px
  - ภาพในการ์ด / ภาพ NPC / ภาพสถานที่: 800 px ด้านยาว
  - ถ้าใช้บนจอความละเอียดสูงด้วย ให้ทำ 2 ขนาด: `ชื่อ.webp` (1x) และ `ชื่อ@2x.webp` (2x)
- ไฟล์ละไม่เกิน 300 KB (ภาพเต็มหน้าไม่เกิน 500 KB)
- พื้นหลังเข้ากับ navy ของ theme (ไม่ใช่ขาวล้วน) หรือใช้พื้นใส (WebP รองรับ)
- ห้ามมีข้อความภาษาไทยหรืออังกฤษฝังในภาพ ข้อความให้ใส่ใน HTML (อ่านง่าย, แปลได้, screen reader อ่านได้)

### พื้นผิว (`textures/`)
- เบา ๆ ไม่ลด contrast ของตัวหนังสือ (หลังปูแล้วคู่สี text / พื้นยังต้อง ≥ 4.5:1)
- ขนาด 256–512 px ต่อขอบกันได้ ไฟล์ละไม่เกิน 50 KB

### ฟอนต์ (`fonts/`)
- WOFF2 ต่อ weight (เช่น 400, 600) และตัดเฉพาะชุดอักขระไทย + ละตินที่ใช้
- ต้องเป็นฟอนต์ที่ใช้ฟรีบนเว็บได้ (SIL Open Font License เช่น Anuphan, Trirong, IBM Plex Sans Thai) ใส่ไฟล์ license ไว้ข้างกัน

## การตั้งชื่อ

- ตัวพิมพ์เล็กภาษาอังกฤษ คั่นด้วย `-`: `secret-eye.svg`, `weather-rain.svg`, `npc-sister-elena.webp`
- ขึ้นต้นด้วยหมวด: `status-`, `weather-`, `period-`, `karma-`, `travel-`, `npc-`, `place-`, `ending-`
- ชื่อสถานที่ / NPC ใช้ id ภาษาอังกฤษที่อยู่ใน scenario (เช่น `place-temple.webp`, `place-forest.webp`) ไม่ใช้ชื่อไทยในชื่อไฟล์
- ห้ามมีช่องว่าง วงเล็บ หรือตัวอักษรไทยในชื่อไฟล์

## ข้อห้าม

- ไม่ใส่ภาพที่เปิดเผยความลับของเกม (ชื่อจริงของ NPC เกรด B, ฉากจบ, เงื่อนไขลับ) ในไฟล์ที่ผู้เล่นโหลดได้ตั้งแต่ต้น ทุกไฟล์ใน `assets/` ผู้เล่นเปิดดูได้หมด
- ไม่ใส่ไฟล์ต้นฉบับขนาดใหญ่ (PSD, AI, Figma, PNG 4K) ไว้ใน repo ให้เก็บต้นฉบับที่อื่น เอาเฉพาะไฟล์ที่ export แล้ว
- ใช้ได้เฉพาะภาพที่มีสิทธิ์ใช้ (วาดเอง, สร้างด้วย AI ที่ให้ใช้เชิงพาณิชย์ได้, หรือ license เปิด) จด source / license ใน `CREDITS.md` ข้างโฟลเดอร์ที่ใช้

## ใช้ในโค้ด

```tsx
import rainIcon from './assets/icons/weather-rain.svg';

<img src={rainIcon} alt="" aria-hidden="true" /> {/* มีข้อความ "ฝนตก" ข้าง ๆ อยู่แล้ว */}
```

ไอคอนที่ต้องเปลี่ยนสีตาม theme ให้ใส่เป็น component (inline SVG) หรือใช้ CSS `mask-image` กับ `background-color: var(--accent)` เพราะ `<img>` เปลี่ยนสี `currentColor` ไม่ได้ ใช้ตัวช่วย `MaskIcon` จาก `src/ui` (GEN-087): `<MaskIcon src={rainIcon} />` ระบายด้วยสีตัวหนังสือปัจจุบัน (`currentColor`) และเป็น `aria-hidden` เสมอ ต้องมีคำกำกับข้าง ๆ

## ไฟล์ชื่อคงที่ (`apps/web/public/`)

ไฟล์ใน `apps/web/public/` ถูก copy ไปที่ root ของเว็บตามชื่อเดิม (ไม่มี hash) ใช้เฉพาะไฟล์ที่ browser หรือเว็บอื่นเรียกด้วยชื่อคงที่ (อย่าวาง README หรือไฟล์ต้นฉบับในนั้น เพราะทุกไฟล์จะถูกเสิร์ฟออกไป)

| ไฟล์ | ใช้ทำอะไร | รูปแบบ |
|---|---|---|
| `favicon.svg` | ไอคอนบน tab ของ browser | SVG สี่เหลี่ยมจัตุรัส viewBox `0 0 32 32` อ่านออกที่ขนาด 16 px |
| `favicon.png` | สำรองสำหรับ browser ที่ไม่รองรับ SVG | PNG 32×32 |
| `apple-touch-icon.png` | ไอคอนตอนเพิ่มไว้หน้าจอมือถือ | PNG 180×180 พื้นไม่ใส (ใช้ navy ของ theme) |
| `og-image.png` | รูปตอนแชร์ลิงก์เกมใน LINE / Discord / Facebook | PNG หรือ JPG 1200×630 ไม่เกิน 300 KB ไม่มีความลับของเกม |

ชื่อไฟล์ต้องตรงตามตารางนี้ (`index.html` จะอ้างชื่อเหล่านี้) ถ้าจะเพิ่มไฟล์ชื่อคงที่อื่นให้บอก Claude ก่อน
