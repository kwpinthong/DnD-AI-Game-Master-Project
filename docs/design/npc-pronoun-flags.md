### กลุ่ม ข: ไม่พบตัวตรวจจับผิด

ไม่พบตัวตรวจจับผิด. ทั้ง 11 คู่ NPC พูด ฉัน / ข้า เป็นสรรพนามบุรุษที่ 1 จริง (ไม่มี ผม = เส้นผม, ไม่มีคำเป็นส่วนของคำอื่น, ไม่มีคำพูดที่ NPC ยกของคนอื่น). `wordCount` ตัดคำแบบทั้งคำ จึงไม่จับ ข้า ใน ข้าน้อย ซ้ำ. ข้อสังเกต: ตัวอย่างข้อความ 60 ข้อความอาจไม่ครบรูปแบบที่ผู้เล่นจริงพิมพ์.

### กลุ่ม ค: ไม่มีคู่

สรรพนามที่ติดคือ ฉัน (amnesiac) และ ข้า (merchant, horizon-watcher). ใน `npc.json` (lore) ของ Lucia / พ่อค้าเร่ / Astra และ catchphrases ใน voice.json ไม่มีคำเหล่านี้เลย (ข้า ปรากฏใน lore ของโนอา / ทหารยาม / ลอร์ดจูเลียน / เลดี้เซเรน่า ซึ่งไม่ได้ติด flag) จึงไม่ใช่ปัญหาโปรไฟล์ไม่ครบตามนิยามกลุ่ม ค.

## 4. ผลเชิงตัวเลข: flag กระจุกที่ 2 NPC

10 จาก 11 flag มาจาก amnesiac (self ว่าง) และ horizon-watcher (self เป็นคำนาม ผู้บันทึก ไม่ใช่สรรพนาม). ทั้งสองไม่มีสรรพนามบุรุษที่ 1 ให้โมเดลยึด จึงมักเติม ฉัน / ข้า เอง. NPC ที่มี self เป็นสรรพนามปกติ (beggar, nun, guard, noble, ...) แทบไม่ติด (merchant หลุดครั้งเดียวใน 5). ข้อมูลนี้เป็นสมมติฐานจากตัวอย่าง 60 ข้อความ ยังไม่ได้ทดสอบเชิงสาเหตุ.

## 5. ตัวเลือกแก้ (C4) สำหรับกลุ่ม ก

ตัวเลข "เวลาที่เพิ่ม" = latency_ms เฉลี่ยของ [ai] purpose=npc_chat ในรอบนี้ (2.15 วินาที) x จำนวน call ที่เพิ่ม.

| ทาง | AI call ที่เพิ่มต่อ 1 แชต | เวลาตอบที่เพิ่ม | สิ่งที่อาจพัง |
|---|---|---|---|
| ก-1 เพิ่มบรรทัดในบล็อกคำสั่ง npc_chat / โปรไฟล์: "เรียกตัวเองด้วย <self> เท่านั้น ห้ามใช้ ข้า/ฉัน; ถ้า self ว่างให้ละประธาน" | 0 | 0 วินาที | ชน prompt ที่ ISK-025 (ชุด B-006) กำลังแก้ขนาน; โมเดลอาจยังหลุด หรือประโยคแข็งขึ้น; ต้องวัด flag ซ้ำ |
| ก-2 ให้ flag นี้ขอ rewrite 1 ครั้ง (เปลี่ยน severity pronoun_mismatch เป็น block หรือให้ rewrite ทำงานเมื่อติด flag + เปิดตั้งค่า rewrite) | 1 เฉพาะแชตที่ติด flag (ราว 0.18 ต่อแชตเฉลี่ยจากรอบนี้; 0 ถ้าไม่ติด) | +2.15 วินาที เฉพาะแชตที่ติด | rewrite ช้าเกิน `styleRewriteMs` / ล้มเหลวแล้วส่งข้อความเดิม; rewrite เปลี่ยนความหมายหรือยังติดซ้ำ; ต้นทุน cost เพิ่มสำหรับ NPC ที่ติดบ่อย (amnesiac, horizon-watcher ติด 100%) |
| ก-3 ปรับ voice.json: amnesiac เพิ่ม self ที่ยอมรับ (เช่น ฉัน), horizon-watcher ยอม ข้า, merchant ยอม ข้า เป็นสรรพนามรอง | 0 | 0 วินาที | ซ่อนการหลุดจริงของโมเดล (flag ลดแต่น้ำเสียงเพี้ยนเท่าเดิม); ขัด note "ละประธาน" ของ amnesiac; Railway ใช้ชุดที่บันทึกใน /admin ต้องแก้ที่นั่นด้วย |

ทางที่แนะนำสำหรับกลุ่ม ก: ก-1 (ไม่เพิ่ม call / เวลา; ลองก่อนแล้ววัด flag ซ้ำ ด้วยชุดทดสอบ 60 ข้อความนี้). ถ้ายังติดสูงค่อยพิจารณา ก-2. การเลือกเป็นของ Nok.

กลุ่ม ข และ ค ไม่มีคู่ จึงไม่มีตัวเลือก.

## 6. สิ่งที่ยังไม่รู้

- never_word 3 ครั้งบน Railway ไม่เกิดเลยในรอบนี้ (0 จาก 60). สาเหตุที่เป็นไปได้: Voice ใน /admin ต่างจากไฟล์ (neverWords คนละชุด), และชนิดข้อความของผู้เล่นจริง (ยาว / ภาษาพูด / ตอบโต้ต่อเนื่องที่ใช้ประวัติแชต) ต่างจากชุดทดสอบ.
- อัตราบน Railway (ราว 56%) สูงกว่าที่นี่ (18%) ด้วยสองเหตุผลเดียวกัน. ถ้า Nok ต้องการยืนยัน ต้องมี export `npc_chat.reply` จาก backup ของ Railway (งานที่ต้องผ่าน Gate Nok).
- แชตหนึ่งใน 60 (noble) ได้ invalid_json 2 ครั้งติด (out 796 และ 941 token จาก เพดาน 1000 ของ ISK-027) แล้วผ่านเมื่อส่งซ้ำ; ไม่ใช่ max_tokens แต่ output ยาวถึง 941 token เป็นสัญญาณที่ควรจับตา.
- npc_dialogue ไม่ได้ตรวจ.
